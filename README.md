# keirin-ev 競輪 期待値投資システム

「当てる」ではなく「オッズが確率より高い目だけを買う」ためのシステム。
GitHub Actions 上で自動実行するので、PCは不要（スマホのGitHubアプリで結果を見る）。

## 見る場所
- **reports/latest.md** … 毎晩更新されるレポート（取得状況・人気別回収率・検証結果）
- **アクション** タブ … 自動実行の成功/失敗

## 自動で動くもの
| 名前 | タイミング | 内容 |
|---|---|---|
| collect | 毎日 01:40 | 前日・前々日の出走表・3連単確定オッズ・結果を取得 → レポート更新 |
| backfill | 毎日 13:10 / 19:10 | 過去に7日ずつ遡って取得（2024-11-01まで）※変数 BACKFILL_ON=true で有効 |
| live | 08:15 / 13:55 / 19:35 起動 | 締切6〜1.5分前にオッズを取り直して期待値判定 → 買い目を「買い目 日付」のIssueに投稿 |
| probe | kdreams.py 更新時 | 取得テスト。debug/ に結果を保存 |

※ live は1日約16時間動くため、非公開リポジトリでは無料枠（月2,000分）を超えます。
自動起動はリポジトリを公開にしたときだけ有効（手動実行はいつでも可）。

## 当日運用
- 設定は **config.json**（mode: paper=紙上運用 / 資金 / 期待値の基準など）
- 買い目は Issue「買い目 YYYY-MM-DD」にコメントで届く（GitHubアプリの通知をオンに）
- 判定した買い目と締切前オッズは data/live/日付/ に保存し、翌朝の結果と突き合わせて
  reports/latest.md の「当日運用」欄に実績を出す
- **このシステムは購入しない。** 買うかどうかは通知を見て自分で判断する

## データ
`data/daily/年/月/日付/` に races / entries / results / odds_trifecta の4つのCSV(gzip)

## 仕組み
1. 1着モデル：競走得点・勝率・連対率・ライン位置・短走路×先行・風×先行・市場の1着確率
2. 2・3着モデル：同ラインの連動を数値化
3. 市場ブレンド：log p = a·log(モデル) + b·log(市場)（市場を事前分布にしたベイズ更新）
4. 買い判定：期待値1.2以上・確率0.4%以上・オッズ300倍以下だけ。なければ見送り
5. 資金：1/4ケリー、1点は資金の1%・1レース3%まで

**判定基準：検証の回収率95%区間の下限が1.0を超えるまで実弾は入れない。**

データ取得元: Kドリームス（個人利用の範囲・アクセス間隔2秒以上）
