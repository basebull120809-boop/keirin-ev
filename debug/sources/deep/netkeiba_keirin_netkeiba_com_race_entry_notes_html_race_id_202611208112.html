小倉競輪場

競輪場

周長距離は400メートル。見なし直線は56.9メートル。
発祥の地でもあるが、現在はドーム型の屋内競輪場に移転し、雨風の影響を受けることがない。
「走りやすさ」をテーマに各競輪場のデータから最も良い組み合わせで設計され日本でも有数の高速バンクとされている。
